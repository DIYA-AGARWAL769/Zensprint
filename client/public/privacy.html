ZenSprint Privacy Policy

Effective date: November 18, 2026

ZenSprint Focus Cop is a Chrome extension that redirects navigation to selected distracting websites to the ZenSprint dashboard. This policy describes what the extension processes and what happens when it works with the dashboard.

Information the extension processes

  • Selected website domains: Chrome's redirect rules check navigation to YouTube, Reddit, Facebook, X/Twitter, Instagram, TikTok, LinkedIn, Netflix, Twitch, Discord, and Pinterest. The extension uses the matching domain to redirect to the dashboard with a distracted_by parameter. It does not read page content, form entries, or passwords on those sites.
  • Temporary exception settings: On the ZenSprint dashboard only, the content script reads the local browser storage values that control an active break and an optionally unblocked site. It checks these values to restore the redirect rules when a break ends.
  • Dashboard address: The dashboard URL configured in the extension popup is saved in Chrome's local extension storage.

Information sent to ZenSprint

When a redirect opens the dashboard, the matching domain is included in the page address. If you are signed in, the dashboard sends that domain to the ZenSprint backend to create a distraction log associated with your account. The backend records the domain, event time, and the roast shown for that event. The extension does not access your ZenSprint authentication token.

Storage, sharing, and retention

The extension stores its dashboard URL in Chrome's local extension storage. Distraction logs and account data are stored by the ZenSprint backend using its hosting and database providers to provide the service. ZenSprint does not sell this information or use it for advertising. Distraction logs can be cleared from the ZenSprint dashboard. Uninstalling the extension removes its local extension storage; it does not delete data already stored in your ZenSprint account.

Your choices

You can change the dashboard URL in the extension popup, remove a temporary exception in ZenSprint, clear distraction logs from your account, or disable/uninstall the extension from Chrome. The extension's redirects can be adjusted through the dashboard's extension controls.

Contact

For privacy questions or requests, use the support contact provided with the ZenSprint Chrome Web Store listing.
